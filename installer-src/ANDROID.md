# Claisum for Android

Android Discord is a native app — direct JavaScript injection is not possible without root.

## What you can do on Android

### Option A: Aliucord (recommended for Android)
Aliucord is a community Discord mod for Android that supports plugins and themes.
Claisum themes can be used as Aliucord themes by copying the CSS.

1. Install Aliucord: https://github.com/Aliucord/Aliucord
2. Import a Claisum theme CSS as a custom Aliucord theme

### Option B: Claisum Companion App (coming soon)
A standalone Claisum Android app is in development that will let you:
- Browse and download Claisum themes and plugins
- Apply them automatically with Aliucord integration

### Export a Theme for Android
In Discord on desktop (with Claisum), open Settings → Themes → select a theme → "Export for Android"
to get a file you can import on your phone.
